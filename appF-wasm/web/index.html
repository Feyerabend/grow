One module, two machines

Chapter 23's machine, the book's machine compiled to WebAssembly 1.0, runs a program twice: once on this browser's own WebAssembly engine, and once on appendix F's machine, wasm.c, itself compiled to WebAssembly and running inside the same engine. What the two print, and how the program ends, must be the same.
