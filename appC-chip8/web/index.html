CHIP-8

The COSMAC VIP's virtual machine, as appendix C describes it: the same machine as chip8.py, which make check holds it to.

Program

One instruction, four hexadecimal digits, to a word; anything after ; is a comment. The program is put at 200.

Machine

The timers count down once every ten instructions, as in chip8.py: at the speed of 10, sixty times a second.

Screen

Keys

The VIP's sixteen keys, in its layout. On a keyboard: 1 2 3 4, Q W E R, A S D F and Z X C V. A key held down answers EX9E and EXA1; a key pressed is what FX0A waits for.
